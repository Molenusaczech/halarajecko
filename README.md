# Halarajecko
A simple markdown-based website to display info about Sportovní Hala Ráječko.
Data is stored in individual markdown files and in config/ folder.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
